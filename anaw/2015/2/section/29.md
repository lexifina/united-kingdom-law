# 29 Public services boards

(1) There is to be a public services board for each local authority area in Wales.

(2) The members of each board are—

- (a) the local authority;
- (b) the Local Health Board for an area any part of which falls within the local authority area;
- (c) the Welsh fire and rescue authority for an area any part of which falls within the local authority area;
- (d) the Natural Resources Body for Wales.

(3) In this Part, a reference to a “public services board” (or “board”) is a reference to the members of that board acting jointly; accordingly, a function expressed as a function of a public services board is a function of each member of the board that may only be exercised jointly with the other members.

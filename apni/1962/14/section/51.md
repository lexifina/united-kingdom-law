# 51 Publication of summary of return as to election expenses at elections.

At [ an election] the returning officer shall, within ten days after he receives from the election agent of a candidate a return as to election expenses, publish in two or more newspapers circulating in the constituency for which the election was held, a summary of the return accompanied by a notice of the time and place at which the return and declarations (including the accompanying documents) can be inspected.

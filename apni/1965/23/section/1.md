# 1 Development value of land.

For the purposes of this Part, land shall, subject to section 3(8), be taken to have a development value where the unrestricted value of that land exceeds the restricted value of that land; and subject to this Part, any reference in this Part to the development value of any land is a reference to the amount of that excess.

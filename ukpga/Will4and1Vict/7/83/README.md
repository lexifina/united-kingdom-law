# Parliamentary Documents Deposit Act 1837

1837 c. 83. Enacted 1837-07-17.

The files here are the text legislation.gov.uk publishes as in force from 1837-07-17, one file per provision. This is the oldest version in this history; earlier versions are not here yet.

Source: https://www.legislation.gov.uk/ukpga/Will4and1Vict/7/83/enacted

# Marriages (Ireland) Act 1846

1846 c. 72. Enacted 1846-08-26.

The files here are the text legislation.gov.uk publishes as in force from 1846-08-26, one file per provision. This is the oldest version in this history; earlier versions are not here yet.

Source: https://www.legislation.gov.uk/ukpga/Vict/9-10/72/enacted

# 139A Analysis of performance

(1) The Commission must prepare and publish an analysis of the Commissioner’s performance using key performance indicators.

(2) The analysis must be prepared and published at least annually.

(3) In this section, “key performance indicators” means factors by reference to which the Commission’s performance can be measured most effectively.

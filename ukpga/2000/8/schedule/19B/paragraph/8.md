# Sch. 19B para. 8 Application of this Part of this Schedule

(1) This Part of this Schedule applies in relation to a liability of an insurer while the value of the liability is reduced under a write-down order.

(2) Where the write-down order is varied, this Part of this Schedule applies as if references to the write-down order were to the order as varied.

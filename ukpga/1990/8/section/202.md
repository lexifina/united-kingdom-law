# 202 Power for Secretary of State to make tree preservation orders.

(1) If it appears to the Secretary of State, after consultation with the local planning authority, to be expedient that a tree preservation order or an order amending or revoking such an order should be made, he may himself make such an order.

(2) Any order so made by the Secretary of State shall, once it has taken effect in accordance with tree preservation regulations, have the same effect as if it had been made by the local planning authority under section 198(1).

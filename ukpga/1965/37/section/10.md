# 10 Application to Scotland.

In its application to Scotland, the Schedule to this Act shall have effect as if—

- (a) any reference therein to a plaintifff included a reference to a pursuer;
- (b) any reference therein to a defendant included a reference to a defender; and
- (c) any reference to security for costs included a reference to cautions for expenses.

# Habeas Corpus Act 1816

1816 c. 100. Enacted 1816-07-01.

The files here are the text legislation.gov.uk publishes as in force from 1816-07-01, one file per provision. This is the oldest version in this history; earlier versions are not here yet.

Source: https://www.legislation.gov.uk/ukpga/Geo3/56/100/enacted

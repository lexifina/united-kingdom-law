# Savings Bank (Scotland) Act 1819

1819 c. 62. Enacted 1819-07-02.

The files here are the text legislation.gov.uk publishes as in force from 1819-07-02, one file per provision. This is the oldest version in this history; earlier versions are not here yet.

Source: https://www.legislation.gov.uk/ukpga/Geo3/59/62/enacted

# Sch. 7 Pt. X para. 1

(1) The following provisions of this Part of this Schedule shall, unless otherwise agreed in writing between the appropriate authority and a telecommunications operator, have effect for the protection of that operator.

(2) In this Part of this Schedule “telecommunications operator” means the operator of a telecommunications code system and “telecommunication apparatus”, “telecommunications code system” and “telecommunication system” have the same meanings as in Schedule 4 to the Telecommunications Act 1984.

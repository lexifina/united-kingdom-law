The files here are the text legislation.gov.uk publishes as in force from 2026-01-19, one file per provision. This is the oldest version in this history; earlier versions are not here yet.

legislation.gov.uk lists 11 changes to this Act that it had not yet applied to the text: https://www.legislation.gov.uk/changes/affected/ukpga/2009/1

Source: https://www.legislation.gov.uk/ukpga/2009/1/2026-01-19

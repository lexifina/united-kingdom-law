# 24AF Aerodrome security plans: duration etc.

(1) An aerodrome security plan must specify the period for which it is to be in force.

(2) In the case of the first plan for the aerodrome, the period specified must—

- (a) begin on the day after the end of the period mentioned in section 24AE(1), and
- (b) end on either the 31 March next following that day or on any subsequent 31 March specified in the plan.

(3) In the case of any subsequent plan, the period specified must—

- (a) begin on 1 April, and
- (b) end on either the 31 March next following that day or on any subsequent 31 March specified in the plan.

(4) An aerodrome security plan ceases to be in force if the aerodrome to which it relates ceases to be one to which this Part applies.

(5) If there is a dispute about security planning for an aerodrome which relates to an aerodrome security plan which is not in force, the Secretary of State may direct that the plan is to come into force at the beginning of a day other than that specified in subsection (2)(a) or (3)(a).

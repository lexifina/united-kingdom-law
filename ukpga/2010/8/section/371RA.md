# 371RA Overview of Chapter

(1) Sections 371RB and 371RE set out how to determine for the purposes of this Part if a company is “controlled” by another person or persons.

(2) Sections 371RC and 371RG set out certain cases in which a non-UK resident company which would not otherwise be a CFC is to be taken to be a CFC for the purposes of this Part.

# Sch. 3 para. 3

In section 463(1) of the Housing Act 1985 (preliminary condition for eligibility for grant: the interest of the applicant in the property) for “may entertain an application for a grant only if” substitute “shall not entertain an application for a grant, other than an application for a common parts grant, unless”.

# Sch. 2A para. 8

As soon as reasonably practicable after an application is made for a property scheme, the Authority must publish a notice which—

- (a) states that an application for a property scheme has been made,
- (b) states the names of the applicant and the non-applicant party, and
- (c) contains a general description of the property scheme to which the application relates.

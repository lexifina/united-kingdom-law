# Sch. 2A para. 21

(1) A transaction of any description effected by or under a property scheme has effect subject to the provisions of any enactment which provides for transactions of that description to be registered in any statutory register.

(2) Subject to that, a transaction of any description effected by or under a property scheme is binding on all persons, despite the fact that it would, apart from this provision, have required the consent or concurrence of any person.

(3) In this paragraph “enactment” includes an enactment comprised in, or in an instrument made under, an Act of the Scottish Parliament.

# 381 Balancing events (on making an election)

(1) Any event described in subsection (2) is a balancing event, but only if an election is made in accordance with section 382 for it to be treated as such.

(2) The events are—

- (a) the relevant interest is acquired as mentioned in section 375;
- (b) the agricultural building is demolished or destroyed;
- (c) the agricultural building ceases altogether to be used (without being demolished or destroyed).

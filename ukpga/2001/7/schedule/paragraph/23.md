# Sch. paragraph 23 Voting by persons with disabilities

In rule 36 after paragraph (4A) insert—

> The same list may be used for each election.
> If it is, an entry in the list must be taken to mean that the votes were given in accordance with this rule in respect of each election unless the list identifies the election at which the vote was so given.

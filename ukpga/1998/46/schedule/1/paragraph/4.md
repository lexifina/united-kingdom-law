# Sch. 1 para. 4

(1) This paragraph applies if Boundaries Scotland submit a report to the Scottish Ministers recommending an alteration in a constituency.

(2) In the report Boundaries Scotland must recommend any alteration in any of the regions which it thinks is necessary to give effect to the regional rules.

(3) A report making a recommendation for an alteration in a region must recommend the name by which Boundaries Scotland think the region should be known.

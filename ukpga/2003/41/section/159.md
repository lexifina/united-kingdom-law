# 159 Computer information

(1) This section applies if any of the special procedure material or excluded material specified in an application for a production order consists of information stored in any electronic form.

(2) If the order is an order requiring a person to produce the material to a constable for him to take away, it has effect as an order to produce the material in a form—

- (a) in which it can be taken away by him;
- (b) in which it is visible and legible or from which it can readily be produced in a visible and legible form.

(3) If the order is an order requiring a person to give a constable access to the material, it has effect as an order to give him access to the material in a form—

- (a) in which it is visible and legible, or
- (b) from which it can readily be produced in a visible and legible form.

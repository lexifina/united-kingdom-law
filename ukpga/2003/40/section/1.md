# 1 Control of ragwort

After section 1 of the Weeds Act 1959 (c. 54) there is inserted—

> Code of practice: ragwort
> The Minister may make a code of practice for the purpose of providing guidance on how to prevent the spread of ragwort (senecio jacobaea L.).
> Before making the code the Minister must consult such persons as he considers appropriate.
> The Minister must lay a copy of the code before Parliament.
> The Minister may revise the code; and subsections (2) and (3) apply to the revised code.
> The code is to be admissible in evidence.
> If the code appears to a court to be relevant to any question arising in proceedings it is to be taken into account in determining that question.

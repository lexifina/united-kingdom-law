# Carriage by Air (Supplementary Provisions) Act 1962

1962 c. 43. Enacted 1962-07-09.

The files here are the text legislation.gov.uk publishes as in force from 2004-08-06, one file per provision. This is the oldest version in this history; earlier versions are not here yet.

# 49 Variation and revocation of enforcement orders

(1) The First-tier Tribunal may, at any time—

- (a) vary a letting agent enforcement order, or
- (b) where it considers that the steps required by the order are no longer necessary, revoke it.

(2) References in this Part (including this section) to a letting agent enforcement order are to be treated as references to the order as so varied.

# 36 Letting agent registration number

(1) The Scottish Ministers must allocate a number to each registered letting agent (the “letting agent registration number”).

(2) A registered letting agent must take all reasonable steps to ensure that the agent’s letting agent registration number is included in—

- (a) any document sent to a landlord, tenant, prospective landlord or prospective tenant in the course of the agent’s letting agency work,
- (b) any property advertisement or communication in relation to the agent’s letting agency work, and
- (c) any other document or communication of a type specified by the Scottish Ministers by order.

(3) For the purposes of this section—

- (a) “advertisement” includes any form of advertising whether to the public generally, to any section of the public or individually to selected persons, and
- (b) “communication” includes electronic communications sent or placed on a web page on a website ... by or on behalf of the registered letting agent.

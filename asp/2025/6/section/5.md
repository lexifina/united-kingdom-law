# 5 Revision of code

(1) The Scottish Ministers may revise the code of practice as it has effect for the time being.

(2) Section 1(2) to (5) apply to revising the code of practice as they apply to making the first code of practice.

(3) A revised code of practice is to come into effect on such date as is specified in it.

(4) Whenever the code of practice is revised, the Scottish Ministers must re-publish the code of practice as revised.

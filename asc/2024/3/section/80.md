# 80 Highways

(1) An infrastructure consent order may include provision authorising the charging of tolls in relation to a highway only if a request to that effect has been included in the application for the order.

(2) If an infrastructure consent order includes provision authorising the charging of tolls in relation to a highway, the order is treated as a toll order for the purposes of sections 7 to 18 of the New Roads and Street Works Act 1991 (c. 22).
